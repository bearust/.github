# Support

## Ask a Question

We use GitHub for tracking bugs and feature requests related to our projects.

Don't know how something works? Curious if a project can achieve your desired functionality? Please open an issue on GitHub with the label `question`, or start a GitHub discussion where discussions are enabled.

## Documentation

Each repository documents itself in its own `README.md`. For the reverse
proxy itself, start with the [bearust README](https://github.com/bearust/bearust#readme) and its operator manual, deployment, and development guides linked from there.

## Contributing

Please see the [contributing guide](/CONTRIBUTING.md) for guidelines on how to best contribute to our projects.

## Community Support

Our projects do **not** offer commercial support. Community support is offered on a best effort basis through GitHub issues, pull requests, and discussions.
